# Gurei Wiki

Independent English guide hub for **Gurei** at
`https://www.gurei.wiki`.

The launch site covers:

- an evidence-backed beginner route and adaptive boss order;
- all ten confirmed Kami plus power-selection logic;
- dodge timing, sword punishes, lives and run resets;
- all 42 public Steam achievement names;
- spoiler-light secrets and side-encounter research;
- Steam Deck Verified status, PC requirements, review and safe download;
- WebSite, Organization, VideoGame, VideoObject, FAQPage, ItemList, Article and
  BreadcrumbList structured data.

## Source policy

- Steam App 2191280, Steam Community and the Astrolabe Games page are the
  primary identity and release sources.
- Demo App 3776080 is used only when clearly labeled as historical three-boss
  context.
- Community strategy is separated from official fact.
- No fake codes, unsupported tier lists, cracks, APK mirrors, trainers or
  extracted game files.
